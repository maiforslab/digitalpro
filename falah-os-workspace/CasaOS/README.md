# Falah OS Community Edition

> **Falah OS Community Edition: The Sovereign Digital Economy in a Box.**
> Forked from the incredible CasaOS open-source project.

Falah OS is a sovereign, Docker-based cloud operating system designed for the global Muslim Ummah — empowering individuals and communities with full data sovereignty and a self-hosted digital economy infrastructure.

## Design Principles

- **Dark-by-default**: Deep Slate / Pitch Black aesthetic
- **Emerald Accents**: Primary color `#10b981` (Emerald Green)
- **Glassmorphism UI**: Frosted glass widgets, backdrop-blur, subtle borders
- **Sovereign First**: Your data, your hardware, your rules

## Architecture

- **Falah OS Core** — Go-based system daemon & REST API
- **Falah OS Gateway** — Reverse proxy & service routing
- **Falah OS App Management** — Docker app lifecycle & iStore registry
- **Falah OS Dashboard** — Vue.js web frontend
